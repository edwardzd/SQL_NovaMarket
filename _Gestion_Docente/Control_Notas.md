## 🎯 Criterios de Evaluación Global

| Criterio | Descripción |
|----------|-------------|
| **Sintaxis** | El código SQL debe ejecutarse sin errores en SQLite. |
| **Integridad** | Debe cumplir con el número de filas esperado en cada ejercicio. |
| **Identidad** | La base de datos debe tener el nombre personalizado (ej: `..._Anyi.db`). |
